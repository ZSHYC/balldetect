# 全量HRNet与DINO：先分清定位、存在判断与时序贡献

日期：2026-09-11。状态：两组seed0完整训练、结果核对、配对分析与固定样例检查已完成。

协议：[Tennis全量因果定位v1](../protocols/tennis-full-causal-v1.md)。单组设置分别见[HRNet](2026-09-10-full-hrnet.md)与[DINO](2026-09-10-full-dino.md)。

## 问题与结论

本次建立共同任务下的两套完整竞争系统，判断早期冻结小头诊断留下的失败是否仍然存在。结论是：HRNet在总体精细定位和检测F1上更好；DINO并非逐片段更差，但它的错误位置更容易通过存在阈值，无球误报也明显更多。两者都能较好拟合训练位置，验证残差需要从来源泛化、读出、监督及实际时序利用继续区分。

这是系统比较。两者的decoder、输出尺度、QFL/交叉熵、presence定义、预训练、优化器和学习率日程均不同；不能据此声称旧backbone优于现代backbone、HRNet更懂motion，或DINO丢失了全部细粒度信息。本次也不充当backbone × motion的2×2归因实验。

## 实际设置与完成证据

同一RGB缓存、同一12,167个训练目标与1,863个验证目标，真实[t−2,t−1,t]输入，只监督t。验证集1,746个有位置目标和117个VC0目标。训练games1–6、验证game7；最终games8–10未参与。共同使用batch8、float32、30epoch、无增强与AMP，按F1@16、其次F1@8选优。30epoch是相同目标遍历预算，不是相同计算量或优化充分性的证明。

HRNet正式代码32d37d4，DINO正式代码327879b。前者选epoch18，后者选epoch7。两者均核对了epoch0–30、有限训练loss、best.pt与选优记录、全部预测的身份/顺序/原标签，以及重新计算的保存指标；均通过。队列正常退出，结果和配对文件已生成。

本阶段实际执行：

## 总体结果

| 指标 | HRNet | DINO |
|---|---:|---:|
| 训练PCK@8 | 99.69% | 98.86% |
| 训练PCK@16 | 99.95% | 99.69% |
| 训练检测F1@16 | 99.92% | 99.59% |
| 验证PCK@8 | 89.46% | 81.44% |
| 验证PCK@16 | 90.44% | 88.03% |
| 验证PCK@32 | 91.12% | 89.81% |
| 验证位置误差中位数／均值，原图px | 2.37／24.68 | 4.95／39.77 |
| 验证检测F1@8 | 90.17% | 79.92% |
| 验证检测F1@16 | 90.65% | 86.26% |
| 验证检测F1@32 | 90.77% | 87.95% |
| 验证检测@16 TP／FP／FN | 1503／67／243 | 1525／265／221 |
| 验证存在判断TP／FP／FN | 1554／16／192 | 1693／97／53 |

位置PCK与检测F1不是同一问题：前者在所有有位置标签的目标上评价预测坐标，后者还应用0.5存在阈值；输出一个错误位置会同时形成检测FP和FN。DINO的检测TP多22个，但FP多198个，不能用较高的检出数掩盖这些错误。

严格8像素容差的差距为8.02个百分点，16像素容差的差距为2.41个百分点，提示精细读出是必须保留的竞争解释。DINO输出格的原图步距为10px，HRNet为2.5px；但10px格中心的几何量化误差上界约为√2×5=7.07px，因此8px容差并非几何上不可达。不能把全部PCK@8差距说成不可避免的量化损失，也不能由这个差距直接推断backbone中的信息已经消失。

训练位置拟合充分不等于验证可迁移。尤其DINO的训练VC0误报为0/405，验证为97/117；这是明显的来源泛化差距，但不能单独定位为absence分支、某个特征层或motion的因果问题。

## 存在阈值实际改变了什么

| 验证结果，16px、阈值0.5 | HRNet | DINO |
|---|---:|---:|
| 输出且位置正确 | 1503 | 1525 |
| 输出但位置错误 | 51 | 168 |
| 拒绝输出但位置正确 | 76 | 12 |
| 拒绝输出且位置错误 | 116 | 41 |
| VC0上输出位置 | 16 | 97 |

DINO少拒绝64个正确位置，但也多输出117个错误位置和81个无球目标；这是检测TP增加22、FP增加198的具体分解。阈上不等于概率校准，也不等于对应可靠。

保持各自选定检查点和全部坐标不变，将存在分数统一置为1，得到以下事后诊断：

| 检测F1@16 | HRNet | DINO |
|---|---:|---:|
| 全部输出预测位置 | 87.50% | 85.18% |
| 预定0.5存在阈值 | 90.65% | 86.26% |
| 本组阈值拒绝带来的变化 | +3.15个百分点 | +1.08个百分点 |

全部输出时两模型的存在F1都为96.76%，甚至高于各自正常存在F1；这是验证集中有位置目标占93.72%的结果，说明存在F1不能代替带定位容差的主指标。该诊断没有调阈值或重新选checkpoint，不能作为改进方法或校准因果证据。数据见[上下文与全部输出诊断](../../outputs/full_heatmap/visibility_prediction_comparison.json)。

### 一个可定位的固定背景干扰

Clip8/0032与Clip4/0005、0006的DINO最大响应都在原图(54.5,664.5)，例图显示该格点位于计分板的小白点附近。随后只按这个确切坐标检查既有预测：验证集有49次argmax落在此处，36次通过阈值，包含20个VC0误报和16个有位置但错位的输出，没有正确命中；分布在Clip2/4/8。训练预测中该格点argmax为0。

这是事后选定格点的精确计数，不是整个计分板区域的标注或全部背景错误率；训练未选中它也不代表训练画面没有类似图形。它给出一个具体干扰位置，不能解释其余全部错误。脚本、逐帧身份及计数见[格点诊断](../../outputs/full_heatmap/dino_prefix_seed0/scoreboard_cell_diagnostic.json)。

## 判断与下一步

停止把这张系统表解释为纯backbone或motion优劣。保留HRNet强竞争参照，以及DINO在部分目标上的不同错误模式；不因现代化前提而掩盖当前系统的总体劣势，也不因总体劣势就断言现代特征没有价值。

下一项只做[完整DINO重复当前帧控制](../protocols/tennis-full-temporal-control-v1.md)：从相同官方前缀与随机新头重新训练[t,t,t]，保持其余条件，与已完成的[t−2,t−1,t]配对。它直接区分真实历史视觉增量与当前图像/读出能力；不能以训练后推理时替换帧代替。

若真实历史没有提高F1@16或降低PCK@8，就暂停在当前SpatialProbe读出上叠加新的cost、门控或远搜索。困难条件与clip贡献继续单独报告。通过也只是时序输入有效的证据，距离新motion representation、跨球种验证和最终2×2归因仍有明确工作。

独立只读审阅支持这一实验次序，并强调输出尺度、监督与presence定义的竞争解释。此阶段没有确认新的运动机制，也没有形成最终论文性能结论。
