# BlurBall 训练侧拖影轴与帧间位移轴诊断

日期：2026-09-10。状态：已完成。协议：[BlurBall训练侧拖影轴与帧间位移轴诊断](../protocols/blurball-development-axis-v1.md)。本轮只读取中心版标签和已有视频元数据，不训练模型。

## 问题与判别依据

这次诊断检验单帧拖影轴能否作为帧间运动方向的条件证据。作者标签中的 `(X,Y)` 是拖影中点，`l` 是原图像素半长度，`theta` 是图像坐标系中的轴角：0°向右、90°向下，并按180°等价。对同一 match/rally 中原始帧号精确相差 Δ=1/2 的双端合法中点，定义

```text
d = p_t - p_(t-Δ)
axis_error = abs(((theta_t - degrees(atan2(dy, dx)) + 90) mod 180) - 90)
```

比较使用当前帧 `theta_t` 标注与历史到当前的中点位移，不使用未来标签。这是标签间诊断，theta/l并不是模型已经能从像素提取的观测。只有当前 `l>0`、theta/l 有限合法且位移非零时才计算轴误差；不可见、`l=0`、零位移和非法字段都不填成0°误差。`l` 不是球半径或球尺寸，因此不计算 `rho`。

拖影描述曝光期间的形状，帧间中点位移跨越另一时间段。轴不一致可能来自反弹、加速度、视角变化、曝光与帧间采样差异或标注不确定性，不能直接称为 motion 标签错误。

## 实现验证

综合测试手算并锁定以下条件：向左位移与 `theta=0°` 为同一轴、向下位移与 `theta=90°` 一致、水平位移与 `theta=90°` 相差90°；`l=0` 和零位移返回缺失角度；原始 Frame 缺口不重编号；不存在的验证/Test CSV 不打开；当前 theta 非法时仍保留合法中心位移对，只取消该对的轴比较。补充测试区分两个分辨率的同半长度桶、互斥缺失轴原因，并验证从保存帧对重建的汇总与首次计算相同。

## 总体结果

| Δ | 合法中点对 | 可比较轴 | 位移 L2 P50 / P90 / P99 / 最大值（原像素） | 轴误差中位数 / P90 | ≤15° / ≤30° / ≤45° |
|---:|---:|---:|---|---|---|
| 1 | 31,986 | 21,479 | 17.05 / 40.87 / 82.59 / 641.88 | 4.65° / 18.58° | 86.42% / 94.99% / 97.27% |
| 2 | 31,076 | 20,944 | 33.38 / 78.81 / 152.86 / 651.19 | 6.34° / 28.84° | 78.26% / 90.47% / 94.47% |

Δ1 的可比较样本中，86.42% 的拖影轴与帧间位移轴相差不超过15°；Δ2 降至78.26%，P90 从18.58°增至28.84°。这支持“单帧拖影轴包含与短时位移相关的方向证据”，但不证明 theta 是有符号速度，也不证明将 theta 直接作为速度监督会提高定位。

Δ1 有10,506个配对因当前 `l=0` 没有拖影轴，另有1个 `l>0` 但零位移的配对；Δ2 有10,132个 `l=0`，没有额外的 `l>0` 零位移对。总体零位移数为277和148，但其中276和148已包含在 `l=0` 组，不能重复扣除。可比较比例分别为67.15%和67.40%，模型不能假设每个可见球都有可用 blur motion。

最大位移超过640像素，尚未逐例视觉核对，不能据此声称已确认真实超高速事件。论文动机应优先使用稳健的分位数与条件覆盖；若要解释极端样本，需要单独查看对应视频和标签。

较长拖影组表现出更小的轴误差：Δ1 中位数从 `(0,2]` 的9.56°降到 `>10` 的2.39°，15°内比例从68.70%升至95.67%。这支持按半长度分析标签中的轴一致性；它仍可能同时受到速度、曝光、分辨率、match和标注清晰度影响，不能解释成“增加 l 会因果改善方向标签”，也不能把GT标签一致率当作模型的motion可靠性。

## 判断与下一步

结果支持继续研究拖影轴这一**可能缺失的方向线索**：`l=0` 时没有轴可解释，较长拖影时标签通常更接近帧间位移轴。下一步先在真实定位模型中按现成l标注分析错误，区分几何上的轴一致与像素中实际可读的证据，再判断是否需要blur相关训练。

若后续使用theta/l，训练标签可以提供辅助监督，正常推理必须从允许的视觉输入预测；直接提供GT theta/l的比较只能明确列为oracle诊断。当前没有据此添加可靠性模块、强制速度监督或GT推理输入。

这次统计不能说明：拖影轴提供运动正负方向、帧间位移等于曝光内运动、较长l因果导致更可靠、模型已能从像素读出theta，或blur监督必然改善定位。是否需要拒绝匹配或其他结构，须由真实模型失败和最接近的先例共同决定。
