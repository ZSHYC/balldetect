# 高存在分数是否掩盖了分散的位置分布？

日期：2026-09-11。状态：有界探索，诊断实现与CPU数学测试已完成；真实forward等待正在运行的训练结束。

本项继承[Tennis全量因果协议](../protocols/tennis-full-causal-v1.md)的数据、标签与坐标规则，仅分析已选[DINO历史组](2026-09-10-full-dino.md)的epoch7检查点。它不训练新模型，不改动正在运行的[重复当前帧对照](2026-09-11-full-temporal-control.md)，不作为独立benchmark。

## 为什么需要这项测量

[完整系统比较](2026-09-11-full-hrnet-dino-comparison.md)发现DINO的阈上有位置错位输出168例、VC0误报97例。现有CSV保存了存在分数与最终坐标，没有保存空间分布，因此尚不能区分：错误输出来自多个位置之间的分散响应，还是来自一个集中但错误的背景峰。

这会改变后续判断。如果错误同样高度集中，单纯给现有分布增加集中度读出就缺乏解释力；如果集中度含有额外区分信息，也应先承认这是现有读出的证据，再讨论新运动机制。不能仅因存在分数很高就称对应可靠，也不能预先把所有误报归给absence分支。

## 从现有实现可直接推导的事实

[SpatialProbe](../../src/ballmotion/probe.py)输出K=72×128个空间logits z，以及一个absence logit a。令

```text
p = softmax([z, a])          # K+1个类别的联合分布
q = 1 - p_absence            # 当前实现保存的“存在”分数
c = softmax(z)              # 只对K个空间logits归一化
v_hat = argmax(z)            # 当前实现输出的位置格
```

于是`p_v = q * c_v`。有位置目标格y的交叉熵可分解为`-log(q) - log(c_y)`，VC0的交叉熵为`-log(1-q)`。该分解不代表参数或优化独立：空间与absence读出共享前缀，q也依赖全部空间logits。

q汇总了所有空间位置的模型质量，而最终位置只选一个argmax。因此在同一个q下，单一位置峰与两个远隔峰可以有不同的局部集中度。反过来，一个集中但错误的峰也可以同时具有高q与高集中度。

归一化熵也不能按字面当可靠度：在9,216个格中只有两个等质量远隔峰时，熵为`log(2)/log(9216)`，归一化后数值较小，但选择其中哪个峰仍有歧义。本项比较实际分布和排序，不为“低熵”预设可靠标签。

这里“存在”始终指协议的有位置类别，包含VC3；不等于当前图像中存在可见球像素。上述代数关系不证明概率校准、物理对应或因果运动利用。若使用完整K+1的p，则邻域联合质量直接是`sum(p_v)`，不能再乘一次q。

## 固定测量与边界

只运行选定epoch7在同一1,863个验证目标上的一次forward，batch8、原精度和原模型输入。读取既有RGB缓存，不重新解码，不读取最终games8–10。正式运行等GPU训练结束后串行执行。

每个目标保存：q、`max(c)`、`H(c)/log(K)`、以预测argmax为中心的条件质量m16，以及`q*m16`。m16的邻域由原图格中心间距定义，半径16px；当前格距10px，所以它等于3×3九个格的概率之和，图像边缘只计有效格。邻域不依赖GT位置。

m16描述量化位置分布的集中度。格中心与真实连续坐标不同，加上硬格交叉熵未直接监督这个区域事件，不能把`q*m16`称为“16px内正确的已校准概率”。它只是本次要检验的固定统计量。

新forward的坐标必须逐目标重现已有预测，q需在rtol=atol=1e−5内相符；身份、顺序与原标签也必须相同。若不符，先定位实现或数值差异，不静默重排、丢行或将新预测混入旧错误分组。

通过复现核对后，报告中的q保留原CSV数值，联合质量也用原q与新测量的m16计算；这样两项排序比较共享同一份基准分数。乘法保持float32，与原模型分数精度一致。

## 在看结果之前确定的分析

沿用旧q≥0.5与16px误差，将样本分为：正确且输出、有位置但错位输出、位置正确却拒绝、错位且拒绝、VC0误报、VC0拒绝。分别报告各分数的p10、中位数与p90；不据结果重新定义组。

固定计分板格(54.5,664.5)的49例作为已有观察引出的事后组，连同是否输出单列。它只描述这个格点，不代替背景区域标注。按9个clip报告分数与排序方向，避免计分板重复或单个clip决定总体解释。

对事件“协议有位置且误差≤16px”，固定比较q与`q*m16`的AUROC，分别报告全体与旧阈上子集，并保留各clip结果。相等分数计0.5，无正例或负例时报告无定义。该排序统计不调新阈值、不重新选择检查点，也不替换已有检测F1或时序对照的判定规则。

支持空间分散解释需要看到：正确组较错位输出和VC0误报具有更高局部质量/峰值、更低熵，同时联合邻域质量的排序优于q。若错误组同样集中、固定背景错误具有高局部质量，或联合分数没有改善排序，就反对“仅靠空间集中度可以解释这些误报”的主张。两类错误可以表现不同，混合结果按条件表述；总体改善若由少数clip主导，结论相应收窄。

即使支持，也只说明现有logits存在未被q表达的信息，不证明新可靠性方法成立或必然提高F1。先等待完整时序控制，不因此新增head、loss、阈值搜索或组合训练。
