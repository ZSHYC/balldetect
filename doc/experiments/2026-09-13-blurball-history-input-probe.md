# 固定权重下重复当前帧：未修复cross的目标失败

日期：2026-09-13。状态：same/cross两组完整验证均完成。协议：[固定权重历史输入诊断v1](../protocols/blurball-fixed-history-input-diagnostic-v1.md)。

## 结论与范围

**直接把历史槽替换为当前帧，不能修复先前固定的cross失败。** match21的202个原@16破坏目标中，仅2个raw位置回到4px内，且这2个仍被拒绝；全体cross定位与输出质量大幅下降。same也下降，在该202例中原本16px内的目标多数失去正确位置。

这项结果结束“靠去掉历史直接修复这些错误”的具体尝试，不证明历史内容完全无害，也不证明球信息已经在某层消失。网络权重固定，但重复帧改变了训练输入分布，因此测到的是这些已训练函数对输入替换的响应，不能等同于一个重新训练的单帧模型。

原模型是same best4、cross best3，输入干预仅为`[t−2,t−1,t]→[t,t,t]`。当前帧、目标、合法窗口边界、全部14,192个验证目标、模型精度、读出和输出阈值不变。两种读出共享本次新q，q可以随输入改变。原历史预测复用保存文件，没有重新计算完整原输入验证，更没有重训旧repeat组。

## 全体验证

位置分母均为12,896个V1。下面使用共同固定15×15/T1重心；“原→重复”都在同一个模型权重内比较。

| 模型 | PCK@4原→重复 | PCK@16原→重复 | 本地F1@4原→重复 | V1拒绝原→重复 | V0误出原→重复 |
|---|---:|---:|---:|---:|---:|
| same best4 | 81.4981%→60.8561% | 85.4916%→62.2364% | 81.4022%→53.0829% | 2,593→7,525 | 336→157 |
| cross best3 | 82.0797%→55.0713% | 85.8716%→55.6374% | 82.2349%→47.4542% | 2,205→8,318 | 432→143 |

same的@4救回70、破坏2,732，净−2,662；cross救回49、破坏3,532，净−3,483。V0误出减少与可见球大量拒绝同时出现，不能只报告前者。原argmax方向一致：same PCK@4从80.3970%降至60.2667%，cross从80.3970%降至54.3269%；不是局部重心单独造成了下降。

cross四场均下降，不能只把该干预在match21上的表现理解成特定场景问题。

| cross群体 | V1数量 | 原 / 重复当前PCK@4 |
|---|---:|---:|
| match18 | 3,987 | 86.7820% / 71.7081% |
| match19 | 1,616 | 87.4381% / 59.5297% |
| match20 | 3,221 | 69.1711% / 31.3878% |
| match21 | 4,072 | 85.5599% / 55.7466% |

大位移条件下下降更大，与原先训练输入控制中历史具有总体价值的证据相容，但分组相关因素及分布变化仍存在；不能仅由该差值声称cross提取了更好的物理运动表征，也不能将d1代理成未测量的rho。

## 先前固定群体：不是看完新输出重新挑错误

以下群体始终由原same/cross固定重心预测及真实标签定义：202例为same<16、cross≥16；74例为same≥16、cross<16。两组都来自match21，均为V1。它们的成员身份、数量在运行前固定，并在新入口中核实。

| 固定群体 | 模型 | 原 / 重复当前PCK@4 | 原 / 重复当前PCK@16 |
|---|---|---:|---:|
| 202个cross原破坏 | same | 64.3564% / 30.1980% | 100% / 38.1188% |
| 同上 | cross | 0% / 0.9901% | 0% / 0.9901% |
| 74个cross原救回 | same | 0% / 6.7568% | 0% / 8.1081% |
| 同上 | cross | 83.7838% / 17.5676% | 100% / 17.5676% |

在固定202例中，cross重复当前后全部拒绝，200个仍为≥16px错位；不存在“去掉错误历史后恢复多数球”的现象。same原输入在这202例全部16px内，重复当前仅剩77例16px内，说明它原先的成功也依赖原输入配置。

在相反的74例中，cross原有74个16px内位置，干预后仅13个保留在4px内，其中只有2个正确输出。这一反向群体进一步显示，替换输入不仅无法救回目标错误，还会破坏原历史配置中的成功。

这些是单个固定函数的输入反事实，仍不能区分历史身份信息、位移关系、可见性、归一化变化或模型对重复帧的不适应。未测试“保持输入分布但只去掉motion”的理想干预，不能把本实验包装成该结论。

## 实现、验证和计算成本

`scripts/analyze_blurball_readout.py`将原批内唯一帧编码、槽位还原、logits及局部提取集中为 `batch_readout`，原读出入口也调用它。新入口[probe_blurball_history_input.py](../../scripts/probe_blurball_history_input.py)复用该函数、既有坐标映射、指标与分组。模型前向处于eval/inference mode，没有优化器或参数更新。

新增定向测试先因缺少 `batch_readout` 失败，随后通过：非排序帧索引的槽顺序、重复当前输入、尾batch、argmax邻域和q均与显式读取一致；已有局部读出测试同时通过。Python编译、Ruff F通过。每模型的原历史真实首batch坐标精确复现，q最大差均为0，再进行完整干预前向。没有因抽取共享函数而重跑已完成训练。

独立定向审查未发现问题，并实际核对两模型各14,192行输出、两种解码与缓存的新q完全相同、原q保持、固定202/74群体、配对方向和验证数据范围。编辑器诊断返回无问题，但不将其描述为完整Python项目类型检查。

same单模型步骤64.36秒、cross60.47秒，包括该模型加载、原输入首batch验证、全体干预forward和CPU拼接；不包含公共metadata准备及后续分组分析。读出阶段峰值allocated显存分别379.90/379.92MiB。每模型只完整forward一次，原输入只做一个真实batch回归，不重复解码；没有把缓存诊断吞吐当端到端部署速度。

## 下一步判断

保留真实历史的总体价值，同时承认当前网络未能在部分可见球上正确利用现有输入。停止追加重复帧、零帧等类似破坏性输入变体，不能用一串分布外退化来代替运动机制研究。

下一项需要直接检查真实输入下，球位置的候选证据是否仍存在于完整位置输出中：先查已有候选/可读性探针能否复用，再决定最小测量。这能区分“正确球仍是可读的次候选但竞争失败”和“当前定位头连有限候选预算内的球证据都未保留”，从而判断是否适合候选对应搜索。该检查尚未运行；GT只可用于离线评价候选覆盖，不能用于推理筛选或初始化。不据本次负结果直接增加新模块或启动长训练。
