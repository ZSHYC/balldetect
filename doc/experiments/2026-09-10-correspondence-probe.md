# 已知球所在格时，冻结特征能否找到历史球？

日期：2026-09-10。状态：已完成。
协议：[Tennis GT query 对应诊断 v1](../protocols/tennis-correspondence-probe-v1.md)。

## 目的与可推翻的解释

[三帧拼接](2026-09-10-causal-stack.md)有初步净收益，仍未解决全部背景误选。下一步不是直接加大搜索：先在GT query条件下检查特征是否能提供对应，以及扩大范围是否带来净改进。

这一实验预测**历史位置**，已知**当前球所在格**，正常模型的逐帧定位成绩则没有这个GT输入；两者不能放进同一个性能排名。本轮也不是后续学习模型的理论上界。局部窗口本身提供位置先验，因此还比较完全不匹配、直接返回当前GT格中心的零位移对照。

## 实际运行与产物

代码版本 `e1ce6a4`，Conda `zshihyc`。复用512×288 DINOv3 ConvNeXt-Tiny stage1冻结缓存，native36×64格；仅CPU、4线程，无新图像解码、无backbone前向、无训练。读取缓存、计算匹配及聚合耗时4.70秒，不含导入及最后JSON写入。

```bash
python scripts/probe_tennis_correspondence.py --cache data/cache/tennis/dinov3_convnext_tiny_512x288_step8_h2_s1 --output outputs/correspondence_probe/stage1_cosine.json
```

230个开发目标窗口中，双端有位置标签的Δ1/Δ2帧对分别215/213个；双端easy分别199/190个；跨native格分别158/191个。未满足双端标注条件的帧对只从本诊断排除，不改变正常定位的230个验证目标。

完整逐帧证据与按clip汇总在 `outputs/correspondence_probe/stage1_cosine.json`。零位移结果由该JSON保存的query格和历史GT坐标直接计算，另存 `zero_offset.json`，没有重新匹配；图为同目录的 `search_range.png`、可导出的 `search_range.pdf`。零位移预测公式为 `grid_to_original(query_cell, (36, 64))`，误差为该中心与 `history_gt_xy` 的欧氏距离。

已通过已知唯一向量位移、局部排除、并列名次和跨格分组的小型测试。实际完整运行结束且结果JSON成功写出。该运行验证CPU诊断通路，没有验证自动检测或可学习cost volume模块。

## 结果

下表PCK@16以原图像素计，几何覆盖指历史GT所属格是否进入搜索集合。覆盖不是PCK的严格上界，因为邻格中心也可能进入位置容差。

| 间隔 | 搜索 | GT格覆盖 | 原始cosine PCK@16 | 去空间均值cosine PCK@16 |
|---|---|---:|---:|---:|
| Δ1，n=215 | R2 | 98.60% | 68.84% | **85.12%** |
| Δ1 | R4 | 100% | 66.98% | 79.53% |
| Δ1 | R8 | 100% | 65.58% | 73.02% |
| Δ1 | 全局 | 100% | 60.47% | 64.19% |
| Δ2，n=213 | R2 | 75.59% | 40.85% | 58.69% |
| Δ2 | R4 | 98.12% | 45.54% | **67.61%** |
| Δ2 | R8 | 100% | 42.72% | 58.69% |
| Δ2 | 全局 | 100% | 37.56% | 46.95% |

**空间先验不能解释全部收益。** 零位移GT格对照的PCK@16为Δ1 44.19%、Δ2 16.43%；对应的较好局部匹配为85.12%/67.61%。在跨格子集，零位移仅24.05%/6.81%，去均值局部R2/R4仍为81.01%/65.45%。因此成功不只是把同格静态自相似算成了球运动。

**并非特征完全没有可用对应。** 在双端easy子集，去均值R2的Δ1 PCK@16为86.43%，R4的Δ2为70.53%；原始cosine相应为69.35%/49.47%。一个简单公共分量处理就改变大量结果，不能把未经处理的cosine失败直接归因于预训练特征不可恢复地丢失运动信息。

**扩大搜索并不单调改善。** Δ2由R2到R4确实同时改善覆盖与匹配；继续到R8/全局，即使覆盖提高，匹配反而变差。Δ1在R2已有高覆盖，扩大范围的主要结果是新增竞争。因此本数据条件更支持“足够范围内保持判别性”，不支持“越全局越好”。这里的先验搜索中心仍由GT提供，真实模型的query发现问题尚未解决。

**原始特征的真球格不总是最相似格。** 全局精确格recall@1/5/10在Δ1原始cosine下为43.72%/60.47%/64.65%，去均值后为53.49%/63.72%/66.98%；Δ2相应为26.29%/38.50%/41.31%和34.74%/48.36%/56.34%。精确格检索与PCK@16不同，不能将后者当作前者。

跨格子集上，真实历史格分数减“历史帧中当前同坐标格”分数的均值，Δ1原始/去均值为0.0114/0.3970，Δ2为−0.00264/0.5331。去均值能削弱某些公共成分的竞争，但全局误检仍多；这不等于证明了相机运动分离或识别到了特定背景类别。

## 研究判断

当前证据允许进入一个**已有机制的局部cost volume基线**：对全部当前位置保留有限位移候选，让定位读出使用当前细位置证据和历史匹配支持。它仍需和三帧拼接、原始/去均值描述子进行对照；本轮GT query的成功率不能替代自动定位实验。是否需要可学习投影、细节分支、多假设或可靠性处理，尚未从这里得到结论。

第一轮候选范围可由本诊断提出Δ1 R2、Δ2 R4，但它们是同一game7上的开发选择，不能写成普适运动上界。时间、范围、预处理和候选分布均有先例，必须在相关工作核对后将其作为基线使用，不能包装为新颖贡献。

多seed三帧比较正在完成。后续仍需验证真实query、无球、困难/遮挡目标、其他比赛和球种；本轮未触及这些普遍性要求，也没有证明完整论文命题。
