# 高速微小球运动表征：第一性原理、证据边界与可证伪研究总纲

本项目研究连续体育视频中的逐帧球定位，以现代预训练视觉骨干为设计前提，以运动证据的表示和使用为潜在论文贡献。本文在既有立项蓝图和第一轮审查基础上，重新检查问题定义、机制归因、直接先例与实验可识别性。主体文献核验覆盖至 **2026 年 9 月 9 日**可访问资料，并于 **9 月 10 日**补查近期条目；没有运行模型训练、完整数据审计或真实性能比较。

本文采用三类标记：**事实**由原始论文或官方资源支持；**推论**由明确假设和逻辑分析得到；**假设**需要后续实验决定。一个合理反例可以否定宽泛主张，却不能证明某个尚未实现的方法一定失败。文献没有检到也不能证明空白存在。

## 1. 研究结论与第二轮实质修订

**保留这个研究方向，但进一步把目标从“设计一种显式 motion 模块”收敛为“在受限计算下，保留并使用足以改善当前球位置决策的跨帧证据”。**显式对应、时间累积、动态先验和联合时空特征，都应成为有资格获胜的竞争解释。

第一轮已经识别空间证据、候选漏失、单球监督捷径和公平比较问题。第二轮还需要增加六项修订：

| 修订 | 为什么会改变研究决策 |
|---|---|
| 把“伪对应”改称“检测可分解的对应解” | 单球检测后配对是合法且可能有效的运动证据；不足之处是特定探针不能区分机制，不能据此否认其研究价值 |
| 搜索问题增加背景竞争维度 | 搜索越远，真球越可能进入范围，也越可能被极端高分背景压过；覆盖提高与匹配提高并非同一件事 |
| 把检测前的时间累积纳入竞争路线 | 若球在单帧候选化前就被丢弃，后续关系模块很难挽回；这同时触及 track-before-detect 的已有前史 |
| 把 patch 相位、位置偏差与空间信息不足分开 | 冻结特征匹配失败不一定来自“球消失”；现代 DINOv3 已有明确位置偏差和延迟消歧近邻 |
| 把标注位置与物理时刻重新对齐 | 拖影中心、轨迹末端、遮挡插值位置不是可直接互换的监督；中心位移也不自动是光流真值 |
| 限制小规模测试来源能够支撑的统计结论 | 数千相邻帧不等于数千独立比赛；精细分桶和 bootstrap 无法创造新的独立来源 |

这一轮不能给出“算法创新已经成立”的结论。能给出的更强结论是：**核心研究风险已经可以组织成一组明确、有限、可推翻偏好路线的实验，而不需要先搭建大模型。**

## 2. 不再漂移的任务契约

### 2.1 目标、输入与排除项

预测目标为公开协议定义的二维球位置及其所要求的存在/可定位状态。输入是同一连续 clip/rally 内合法的 RGB 帧；允许相机连续运动。第一阶段不研究切镜、跨镜 ID、SLAM、三维重建或新增人工密集标签。

“逐帧输出”不等于必须在线。第一版可以使用固定、明确的前瞻，例如中心三帧输入；所有主要对照共享相同未来信息。若后续讨论在线能力，需要重新训练或验证因果版本，并报告等待时间。

### 2.2 最少需要区分的变量

| 变量 | 定义 | 为什么不能省略 |
|---|---|---|
| \(I_t\) | 解码后的目标帧 | 是视觉输入，不是瞬时三维状态 |
| \(\tau_t\) | 原始时间戳或可追溯帧时间 | 不能用稀疏标注序号替代 |
| \(c_t\) | clip/rally 与来源标识 | 限制窗口、状态和数据划分 |
| \(a_t\) | 此帧是否有有效标签 | 缺标与无球必须分开 |
| \(v_t\) | 数据定义的 visibility/status | 各数据集枚举含义可能不同 |
| \(y_t\) | 协议二维坐标 | 不默认等于曝光中点的物理中心 |
| \(z_t\) | 分析中的潜在物理状态 | 现有中心标签通常不能完整验证 |
| \(\mathcal T_t\) | 合法输入时间集合 | 明确帧数、间隔和前瞻 |
| \(B\) | 延迟、显存和训练资源约束 | 尚无硬件实测，不虚构预算值 |

任何数据 adapter 都应保留原始标签，再映射到统一评价状态。统一状态不能覆盖掉原始定义，否则后面无法检查差异究竟来自模型还是标签语义。

### 2.3 主要研究对象

可以研究：当前可见弱球的定位、多个疑似球位置之间的消歧、短时遮挡下的协议位置估计、跨时间证据的计算分配。

必须分开报告：视觉可定位帧与依赖轨迹估计的遮挡帧；自动发现与给定 GT 点的跟踪；原始标签与派生插值标签；训练适配后的跨球种有效性与零样本泛化。

## 3. 成像模型：运动首先改变观测，而不只是增加一个位移向量

### 3.1 一个足够用于推理的观测模型

令连续时刻的成像亮度为 \(L(x,\tau;z,\gamma)\)，其中 \(z\) 包含球状态，\(\gamma\) 包含相机和场景因素。帧观测可写成：

\[
I_t=\mathcal Q_t\left[\mathcal S_t\left(\int w_t(\tau)L(x,\tau;z,\gamma)\,d\tau\right)\right]+\epsilon_t.
\]

曝光积分、空间采样和编码会共同改变球的亮度、形状和可分性。这个公式是分析工具，不要求为论文估计全部成像参数。

高速球的困难不只在于位移大。相同的位移可能对应清晰短曝光或严重长拖影；相同的拖影长度可能来自不同曝光时间、速度和观察方向。相机跟球时，球的像素位移还可能很小。

### 3.2 不可识别性不是模型不够大

若两个不同潜在运动过程产生几乎相同的输入窗口，而标签要求不同位置，那么仅从该窗口无法可靠区分二者。多层 attention 不会凭空增加观测。模型仍可以学习训练分布中的偏好，但输出应理解为条件估计。

相反，“肉眼看不清”或“一个线性探针失败”不证明输入无信息。网络可能利用细微强度、压缩残差或空间上下文。因此，应说“在已测输入和读出条件下没有获得可靠增益”，不要轻率声称信息已经彻底丢失。

### 3.3 物理对应、目标中心对应与标签对应

光流通常讨论成像点跨帧的运动；本项目标签通常给一个球位置。一个旋转、变形、拖影变化的球，其标签中心未必对应同一个表面点。用 \(y_t-y_j\) 检查中心位移很有用，但这不是在给邻域每个像素提供真实稠密光流。

对于模糊或遮挡帧，最准确的表述往往是“协议球位置之间的关系”。除非有额外证据，不把它升级为真实速度、曝光期内轨迹、材料点 correspondence 或三维运动。

## 4. Motion representation 应当怎样定义才可研究

### 4.1 用决策相关性定义，而不按模块名字定义

设模型从窗口得到表示 \(R_t=\phi(I_{\mathcal T_t})\)，随后预测 \(\hat y_t=h(R_t)\)。真正关心的是：在既定预算与监督下，该表示是否使最终任务损失下降，尤其是否利用了单帧不能充分利用的证据。

一组明确的对应概率可以是 motion representation；时间卷积、差分、沿候选路径的证据累积也可以。只有最终一个坐标并不表示内部没有运动信息；保留一个巨大相关体也不表示这些信息被有效使用。

### 4.2 理想信息价值与实际模型收益不能混淆

把任务目标写成 \(Y_t=(v_t,y_t)\)，采用预先定义的联合损失：已知状态参与状态项，有合法坐标的样本参与位置项，缺标项屏蔽。比较使用同一固定评测分布和遮罩。设仅用当前帧的理想最小风险为 \(R^*_{one}\)，使用完整合法窗口的风险为 \(R^*_{window}\)。若后者允许忽略邻帧，则：

\[
R^*_{window}\le R^*_{one}.
\]

这是关于可用信息的推论，不是“实际增加帧数总能提高精度”。有限容量、有限训练、噪声、成本分配和优化失败都可能使实际时序模型更差。

同样，邻帧与标签存在条件统计相关性，不保证在选定定位容差和计算预算下有可见收益。不要以抽象信息量取代真实定位实验，也不要因为一个时序实现失败便否定所有 motion 价值。

### 4.3 动态先验不是不合格的贡献

可以把后验示意写作：

\[
p(y_t\mid I_{\mathcal T_t})\propto
\text{观测支持}\times\text{跨时间约束}.
\]

这不是唯一可识别的分解；训练得到的神经网络一般不会自动把两者严格分开。论文可以研究更好的任务相关联合表示，不必证明一个“与 appearance 完全正交”的纯运动子空间。

需要避免的只是把历史预测当成当前直接视觉证据。若主要改善发生在完全遮挡帧，应讨论动态推断；若主要救回当前弱可见球，应提供视觉关系或时间累积的相应证据。两条路线均可能有价值。

## 5. 对第一轮最强质疑的再反思：单球对应解并不天然低级

### 5.1 保留反例，收紧裁决

若当前和历史帧球分数为 \(a_t(u),a_j(v)\)，则：

\[
C_{sep}(u,v)=a_t(u)+a_j(v)
\]

在固定 \(u\) 对 \(v\) 做 softmax 时，当前项抵消。只在 GT 当前球点查询历史的探针，可能被 query-blind 的历史检测器取得高分。

这个反例证明的是**该探针不能独立识别关系机制**。它不证明这种表示无用，也不证明单球任务必须引入多实例数据才有论文价值。若只有一个任务球，语义检测后配对本来就可能是有效解。

### 5.2 合理的研究门槛

新方法需要超过共同预算下有竞争力的分数配对、分数加几何和简单时序模型，并说明其收益与所声称机制相符。无需证明“绝对纯粹的物理对应”，也无需为排除所有捷径扩展到新增人工标注。

对于球位置以外的查询，只能按当前任务标签评价是否应关联到任务球，不能把每个非球点标为“物理上无对应”。背景线条当然可能有正确光流，只是数据没有它的对应标签。

### 5.3 对照也有表达能力

“分数＋几何”若使用很强的时间网络，它可能已实现复杂动态推理；它不是无 motion 对照。比较时应把它称为低维预测上的时序基线，记录参数、帧数与训练机会。

如果该基线与新相关表示相当，结论应是：当前条件下，密集特征关系没有显示额外价值。不能说整个任务不需要 motion，也不能通过故意减弱轨迹基线维持新模块优势。

## 6. 失效链：应定位到处理环节，而不只给错误起名字

| 环节 | 可能失效 | 最小区分证据 | 不能据此跳到的结论 |
|---|---|---|---|
| 输入形成 | 缩放、曝光、压缩削弱球 | 同帧不同合法输入处理的受控对照 | 一定需要更大骨干 |
| 特征编码 | 层位、patch 相位或位置偏差影响读出 | 固定读出条件的层/相位探针 | 球信息绝对不存在 |
| 查询产生 | 球没进入当前或历史候选 | 自动候选覆盖，特别是困难集合 | 关系打分器一定差 |
| 搜索支持 | 搜得够远但实际采样错过有效位置 | 固定帧对和特征的支持集合审计 | 名义感受野就是有效覆盖 |
| 关系评分 | 背景、模糊或语义相似项压过真球 | 真值附近的 rank、分数间隔、背景竞争 | 必须增加搜索范围 |
| 假设压缩 | top-1/均值/筛选过早丢失真分支 | 相同关系分数的不同压缩对照 | 多峰自然就是概率校准 |
| 跨时间融合 | 错误历史被传播、背景一致性压制球 | 相同定位头的受控使用/移除关系 | 对应正确就一定有益 |
| 位置读出 | 偏置、量化、阈值、后处理改变结果 | 统一坐标变换与同等读出机会 | 所有增益都来自 motion |
| 评价与划分 | 漏检被排除、同源泄漏、标签定义错位 | 评价器检查和来源级结果 | 总 F1 高就能确认机制 |

这些环节有相互作用，不要求每个错误唯一归属一格。价值在于安排能改变一个因素的实验，缩小解释集合。

## 7. 现代骨干的新增审查：位置偏差和 patch 相位

### 7.1 DINOv3 的优势不能替代几何验证

DINOv3 的训练本身已经针对 dense feature 的局部性设计了 Gram anchoring；因此“基础模型只懂全局语义”是过度概括。与此同时，强 dense 表征仍需针对 tiny-ball 条件验证。ConvNeXt 的浅层分辨率与 ViT-S/16 的 token 网格不同，不能仅用模型新旧比较。DINOv3 原文[^s1]

**新近邻：INSID3。**该工作揭示 DINOv3 跨图匹配中与位置相关的相似响应，并通过无训练的子空间处理缓解。它原本研究有示例条件的分割，不能直接证明球定位效果，但足以否定“匹配失败只可能因 tiny support 不够”的单因解释。INSID3，CVPR 2026[^s2]

### 7.2 相位变化是几何问题，也是输入分布问题

球相对 patch 网格的相位改变时，颜色与背景在 token 内的混合会改变。步长采样、位置编码与边界处理都可能影响平移等变性，这已有专门的 ViT 工作，不是待发明的新主题。Making Vision Transformers Truly Shift-Equivariant，CVPR 2024[^s3]

最少测三个量：输出随已知平移后的坐标误差、真位置附近的描述子排序、当前位置单帧定位率。只看 cosine 下降不够，因为网络可能在另一种通道编码中保留位置，读出仍然准确。

全图平移实验只在有效重叠区域评分，排除 padding。变换生成、裁剪坐标与读出反变换保持一致。它检验几何稳定性，不等于真实相机运动，也不等于将相邻帧位移这一因素独立改变。

### 7.3 不预设位置去偏一定有益

同位置响应可能妨碍远位移匹配，但球场位置先验也可能帮助检测。若尝试去偏，参数只能由训练/验证规则或不含测试目标信息的合成输入确定；同时检查定位获益与损害。

本阶段不把去偏、等变骨干和通用上采样全部变成新模块。它们首先是排除错误诊断的控制手段。若一个既有简单修正已经解决主要问题，就不能把修正后的收益归给后续 motion 结构。

## 8. 搜索的第四个维度：背景竞争

### 8.1 覆盖与辨认的方向可能相反

在固定特征和候选评分下，扩大支持集合通常不会减少真位置是否被纳入的几何覆盖；但加入更多背景候选，可能降低真球的排名和 softmax 概率。

因此，原来的“tiny support × large displacement × efficiency”应补上**混淆候选规模及分数尾部**。它不是新的普适理论名称，而是当前实验设计遗漏的一个变量。

### 8.2 可复算反例：更远搜索可以降低正确率

假设真对应分数固定为 3，背景分数 \(Z_i\) 相互独立且服从标准正态，仅作为说明模型。令 \(\Phi\) 为其累积分布，则：

\[
P\left(\max_{1\le i\le M}Z_i>3\right)=1-\Phi(3)^M.
\]

| 背景候选数 \(M\) | 至少一个背景超过真分数的概率 |
|---:|---:|
| 1 | 0.135% |
| 64 | 8.282% |
| 1,024 | 74.923% |
| 36,864 | 接近 100% |

这些是已复算的数学示例，**不是球数据上的测量**。真实相似度不服从独立正态，候选之间也高度相关，不能用此表预测真实失败率。反例只说明：覆盖增加不蕴含检索成功增加。

经典 Needle-Match 已讨论噪声和模糊下，不受限 patch 匹配可能拟合退化而非信号；扩大上下文与提高定位精度之间也早有研究。这项前史进一步限制“更可靠远搜索”的宽泛创新表述。Needle-Match，CVPR 2016[^s4]

### 8.3 搜索实验至少同时画四条曲线

随搜索半径或候选预算变化，分别报告：几何/标签覆盖、给定覆盖时的正确排名、最终定位误差或成功率、实际时间与显存。条件排名同时在所有范围共同覆盖的固定帧对子集上报告；新增覆盖样本另列，避免把新增困难帧的组成变化误判成背景竞争。背景竞争可以用高分错误候选数量和真/假分数间隔作代理，不需要人工给所有反光点分类。

必须固定编码器、帧对与训练条件，才能先研究搜索范围自身的影响。若扩大半径同时换层、加通道、加帧或换 loss，结果只能说明组合配置变化。

### 8.4 相同相关条目数不等于相同搜索能力

均匀远采样可能漏过细小有效支持；密集局部采样可能根本到不了球；高分候选采样可能在当前弱球上过早失败。需要记录**实际查询坐标和局部细化可到达的位置集合**，不能仅看采样数量或名义范围。

ASpanFormer 已根据预测不确定性调整注意范围，同时维持有限采样；“置信驱动扩大搜索”本身已有先例。对 tiny-ball 的可能问题是范围变宽时采样密度是否过低，而非此前无人考虑自适应范围。ASpanFormer，ECCV 2022[^s5]

## 9. 多假设：覆盖、概率、分支身份和决策是四件事

### 9.1 Top-K 不是天然的新表示

最新的 Preserve, Then Resolve 已用冻结 DINOv3 研究真对应不在 top-1、但保留在 top-K 中的情形，并延迟到后续几何估计消歧。它使用的跨视角几何条件与单球视频不同，不能直接搬运其求解器；但“保留多候选再解决”的框架已经是直接近邻。Preserve, Then Resolve，arXiv 2604.23670v3[^s6]

更早的光流工作也已经结合多假设和不确定性估计。多峰数量、mixture 或一个 confidence gate，都不能独立构成新颖性。Uncertainty Estimates and Multi-Hypotheses Networks for Optical Flow，ECCV 2018[^s7]

### 9.2 截断后的高置信可能是假的

假设完整候选分布有 0.9 的概率质量位于被删除位置，保留的两个候选各占 0.06、0.04。重新归一化后得到 0.6、0.4；它们只表示**给定保留集合**的相对偏好，没有说明集合外还存在大量可能性。

因此，稀疏关系中的 softmax 或熵一般是条件量。不同候选数、不同温度、不同分数归一化下，不直接比较其值来断言“更可靠”。搜索漏失、候选内排序和最终使用风险需要各自验证。

### 9.3 宽尾分布不等于两个不同空间峰

SEA-RAFT 的混合 Laplace 形式包含共享位置参数、不同尺度的分量，主要帮助处理普通与不确定样本。不能因为它叫 mixture，就说它等价于保留两个相隔很远的球位置；也不能因此声称多假设光流是空白。SEA-RAFT，§3.2[^s8]

论文若使用“multi-hypothesis”，必须说清：保留的是多个位置、多个速度、多个历史路径，还是一个位置周围的误差尺度。对 soft-argmax，两个远峰可能平均到没有球的位置；是否需要选择峰还是输出均值，取决于最终损失和评价规则。

### 9.4 一致性不是正确性的同义词

两个方向都错配到相同背景结构，仍可能满足循环一致性；一个对增强稳定的错误模型也可能持续错误。一致性可作为训练信号或风险代理，但不是无需标签的真值。

U²Flow 已以增强一致性学习不确定性并用于光流改进，说明相关思路已有近期直接工作。对本项目仍需在有可信中心标签的帧对验证，且不能把整个图像上的好校准外推到球区域。U²Flow，CVPR 2026 / arXiv 2604.10056，§3[^s9]

## 10. 检测前使用时间：一个不能被弱化的竞争路线

### 10.1 两种处理次序

次序 A：每帧提取特征 → 每帧只保留少量显著候选 → 候选之间匹配与推理。

次序 B：保留较弱的空间响应 → 在多个可能路径或对应位置上汇集时间证据 → 再决定球位置和是否保留候选。

若每帧真球分数都低于筛选阈值，但沿真实路径的证据持续存在，B 可能成功而 A 已无机会。这是检测前时间累积的经典动机，不能包装成首次发现。

### 10.2 一个最小的分析模型

对路径 \(\pi=(u_j)\)，考虑：

\[
S(\pi)=\sum_j s_j(u_j)+\lambda\sum_j\psi(u_j,u_{j-1},\Delta\tau_j).
\]

第一项是观测支持，第二项是允许位移的关系或动态约束。这个式子可描述许多已有检测、跟踪和动态规划思想，不是新方法。

它给出有用的比较问题：**是否必须在高维特征上显式做 correspondence，还是较弱的单帧响应加合理时间累积已经足够？**如果后者足够，新论文可以研究更有效的弱证据累积，但不应继续宣称核心收益来自高维描述子匹配。

### 10.3 不能把时间累积基线故意做成强匀速假设

体育球会击打、落台、反弹、被遮挡；完全固定匀速路径容易失败。合理基线可以在固定短窗内容许转折或使用宽松转移代价。它也必须计入搜索成本，不能免费给它 GT 轨迹。

反过来，时间累积也不万能。背景线条可能提供更稳定的响应；长时间积累可能增强错误路径；球跟随相机时相对背景变化不同。它与显式对应一样需要覆盖、错误竞争和定位三段证据。

### 10.4 当证据稀弱时，“当前候选先过关”可能就是错误次序

第一轮推荐的单侧历史候选×稠密当前网格，仍要求历史端先提供可信锚点。简单时序基线中保留不经过逐帧 top-k 的稠密时间卷积或响应累积，便可作为最小检测前对照。如果困难帧连续出现且早筛选漏失明显，再考虑显式路径累积；不提前新增一套 DP 工程。

这不会要求第一版做一个完整多目标跟踪器。先做有界短窗、共享空间响应、相同时间预算的对照，已经足以检查“早筛选是不是主要瓶颈”。

学习式 NeuralTBD 已采用时间累积后产生轨迹候选；其任务是 RF 室内人体跟踪，不能将其指标搬成 RGB 球检测证据，但必须承认计算次序的先例。Neural Dynamic Programming 也已研究学习式 TBD 与状态剪枝。NeuralTBD，IJCAI 2024[^s10]、Neural DP-TBD，ICASSP 2024[^s11]

## 11. 监督测量：本轮最需要落实的数据修订

### 11.1 同名的球位置可能不是同一个物理量

| 数据 | 当前一手证据支持的坐标定义 | 必须保留的限制 |
|---|---|---|
| TrackNet 原始 Tennis | 快速拖影场景采用轨迹 latest position | 不自动等于拖影中点或曝光中点球心 |
| 当前 Shuttlecock / TrackNetV2 发布 | 给出 X/Y 和 visibility | 不能未经 release 证据就继承旧版羽毛球的端点规则 |
| BlurBall | 人工拖影线段的中点、方向、半长度 | 中点是图像约定，不是经过曝光标定的瞬时物理中心 |
| OpenTTGames | 发布帧索引对应的球坐标，模型辅助标注 | 物理时刻和具体中心计算方式尚不明确；缺键不是 absence |
| TTA / TOTNet | 可见/部分遮挡为直接中心；完全遮挡为轨迹一致估计 | 后一类没有可供逐点视觉匹配的当前球证据 |

来源：TrackNet 数据定义[^s12]、Shuttlecock 作者说明[^s13]、BlurBall 正式论文 §3[^s14]、OpenTTGames 官方页[^s15]、TOTNet 正式论文 §3[^s16]。

**不能据此禁止所有跨数据集训练。**可采用数据集条件、独立输出约定或各自训练适配；关键是不把不同标签当同一种物理真值，并把适配方式写清。第一阶段分别训练、分别评价，最便于归因。

### 11.2 拖影轴没有自动提供速度符号

在直线拖影近似下：

\[
p_\pm=y^{mid}\pm l(\cos\theta,\sin\theta).
\]

将 \(\theta\) 改成 \(\theta+\pi\) 只交换两端，不改变可见线段。PCA 主轴尤其有这个符号不确定性。进一步核对 BlurBall 官方固定提交后，已确认 CSV loader 的字段为 `Frame, Visibility, X, Y, l, theta`，角度以 degree 传入关于中心对称的线热图；evaluator 同样按 180° 周期比较方向。因此其公开训练与评估中的 `theta` 是无向 orientation，不能直接作为 signed velocity / heading 真值。原始 CSV 的完整角度取值域与人工画线起止端排序仍未文档化，但这不影响上述结论。[^s32]

若监督是无向轴，可评价模 \(\pi\) 的误差或使用双角表示。帧间中心位移可以提供另一个有向量，但不能忽视击球、反弹、遮挡、曝光差异和端点/中点约定。

因此，“blur 方向与帧间 displacement 必须一致”的强 loss 不应默认加入。它至多是条件成立时可检查的几何关系。

### 11.3 用两个量替代当前不可直接测得的 \(\rho\)

题设 \(\rho=D/d\) 很适合解释问题，但大部分主数据没有逐帧真实图像球径 \(d\)。不要把热图 sigma、网络预测框径或 BlurBall 的 \(l\) 当作分母。

主分析先用：协议坐标位移 \(D_{px}\) 与时间间隔 \(\Delta\tau\)；在 BlurBall 上额外用已有拖影半长度 \(l\)。若需要分辨率归一化，可报告 \(D_{px}/\sqrt{HW}\)，明确它不是 displacement/ball-size。

模型预测尺寸或对比可以成为诊断代理，但不能据待比较模型自己的预测划分一个“客观 tiny/high-speed GT 桶”。这会使困难定义随方法变化。

### 11.4 标签制作本身可能带有动态先验

对于 \(y_t=z_t+\epsilon_t\) 的简化模型，标签位移误差为 \(\epsilon_t-\epsilon_j\)，其方差还取决于跨帧标注误差的协方差。轨迹平滑或插值可能使标签差分看起来异常稳定，却不意味着物理测量更准确。

可以自动检查连续相同坐标、固定量化步长、很长的精确线性片段和异常二阶差分；这些只是 provenance 线索，不能反向证明每条标签如何产生。

对完全遮挡的插值位置，因果模型可能无法从过去唯一预测；这不构成训练泄漏本身，也不使公开评价失效。但包含未来输入的模型更容易拟合此类后验约定，比较时须单列。

### 11.5 不新增人工标注也能保持诚实

保留官方指标，并增加基于现成 visibility 和已知 provenance 的分层。对于无法逐帧区分“直接人工、工具辅助、轨迹估计”的数据，只在可确认层次报告，不能臆造精确 mask。

读视频和检查现有 CSV 是审计，不需要重新标一套数据。若某个分析量缺少标签，第一选择是收窄主张或使用明确代理，而不是要求人工补齐。

## 12. 两个容易被忽略的选择效应

### 12.1 空间基线失败集合并不能独立证明 motion 救回

设 \(\mathcal H_A\) 是由单帧模型 A 失败定义的困难集合。另一个随机种子训练的单帧模型 B，错误与 A 不完全重合，便可能在 \(\mathcal H_A\) 上取得很高“救回率”，即使完全不用邻帧。

所以 \(\mathcal H_A\) 仍是合法诊断集合，但其结果不能单独归因于 motion。一旦要用该集合决定研究路线，就加入一个独立训练的同类单帧模型，观察自然错误互补的规模；不必等待最终主表才发现这项混杂。

不必启动就训练许多 ensemble。完整测试集上的配对任务差值是主证据；困难集合是解释图。若采用多 seed 共识或 out-of-fold 困难定义，应预先固定规则，避免看新方法结果后重选集合。

### 12.2 双端有标签的匹配样本不是全体定位帧的随机子集

可见—可见、双端可信坐标的帧对，通常更容易被评价；遮挡、出画、强模糊和稀疏标注会改变其组成。只在这部分得到好 rank 或校准，不能直接外推到全部困难帧。

每个协议至少记录三项数量及分布：全部有目标帧标签的样本；可评价中心关系的帧对；固定空间困难集合。其中后两者的交集也要报告。位移、visibility、数据来源、可用 blur 属性不应被数量汇总掩盖。

缺失机制未知时，不任意加逆概率权重来制造“无偏估计”。匹配结论限定于可监督范围；完整定位仍在所有合法目标帧上按原协议评价，未标注邻帧继续作为输入。

## 13. 实验需要四个层次，不能用一张消融表承担所有证明

### 13.1 固定表示的机制诊断

冻结同一个 encoder、单帧候选头和单帧分数。从共同的候选池或特征网格出发，只改变某项搜索/压缩规则。

若研究候选选择，允许不同选择器产生不同子集，但起点和预算一致；若研究关系打分，则固定候选集合与坐标。不要同时改变候选头、辅助监督和匹配器，却把召回变化解释成搜索机制效果。

### 13.2 允许重训的竞争基线

各方法按合理且相近的调参机会训练。比较单帧、低维预测上的时序、简单特征时序、显式中心关系、检测前累积。它回答现有条件下什么方法更有效，不声称唯一识别物理原因。

### 13.3 完整联合系统

允许新机制改变编码器与候选质量，报告最终收益；同时记录候选召回是否因联合训练提高。给主要时序基线同样的辅助标签机会，排除额外前景/中心关系监督单独造成的增益。

“固定表示诊断”与“联合训练成功”可以不同，不构成矛盾。前者定位因素，后者验证实际算法价值。

### 13.4 输入或内部量的受控干预

删除关系、置换关系、改变帧顺序或施加已知几何变换，可以提供敏感性证据；它们可能制造分布外输入。应与重训消融共同解释。

证据强度可以分成四种：

| 证据 | 说明什么 | 单独不能说明什么 |
|---|---|---|
| 依赖性 | 模型输出依赖某输入/关系 | 该关系正确或物理可识别 |
| 选择性 | 标注中心关系相对错误候选得分更高 | 必然改善当前位置 |
| 任务效用 | 完整定位风险下降 | 增益唯一来自某个内部机制 |
| 几何一致性 | 已知坐标变化下表示/输出合理变化 | 真实场景全部因果因素已被控制 |

多类证据相互支持时，主张“与任务定义一致的跨帧机制”。不把任何单一干预称为机制的唯一证明。

## 14. 评价必须拆开位置、状态与关系

### 14.1 F1 上升可能只来自状态预测

如果两个模型的最大响应坐标完全相同，只是时序模型更准确地决定是否输出，F1 也可以提升。该结果有用，但不等于坐标更准确。

在已知可定位帧上，强制每个方法给出一个位置，比较 PCK/中心误差；同时独立报告状态判别、完整带阈值定位指标。这里强制输出只用于已知可定位集合，不应用于无球帧。

阈值从验证集固定。分别统计：坐标改变、状态改变、两者同时改变；条件 TP 的坐标误差仅作补充，避免删掉漏检后得到漂亮误差。

### 14.2 关系正确率的命名要符合监督

建议使用 **center-pair retrieval / 标注中心关系检索**，并给定原图容差。点特征、小邻域特征与最终定位可能表现不同；某个中点描述子不稳定，不证明整段拖影无法提供有效运动证据。

对搜索集合漏失、候选内排序错误、标签不可评价分别计数。单球数据没有背景逐点光流真值，不计算虚构的全图匹配 accuracy。

### 14.3 候选外输出不等于候选外证据传输

关系信号 scatter 到候选后，融合卷积或 attention 可能影响候选外；密集外观分支也可能独立在那里生成正确峰。因此，原始候选范围并不总是最终可达范围。

先记录显式搜索集合、scatter 位置和已知局部细化支持；若融合全局可达，不强行声称严格几何召回上限。再比较合理的 appearance-only、关系移除和 full 输出：在候选外的正确位置，关系是否改变了分数、排名或结果？这只是传输的诊断证据，不是整个网络的唯一因果归因。

### 14.4 风险—覆盖要保留完整任务

拒绝关系与拒绝球输出是两个动作。可以拒绝不可靠历史、同时由当前视觉分支输出球；也可以因当前状态不明确拒绝定位。

报告拒绝比例、剩余关系误差和完整定位表现。若拒绝困难帧后条件误差降低、完整召回下降，必须同时展示。null 的监督仅使用可定义的事件，不能拿缺标当 no-match。

## 15. 相机运动、时间间隔与合成控制的边界

### 15.1 图像残差不自动是独立球运动

背景映射 \(W_{j\to t}\) 下的残差 \(y_t-W_{j\to t}(y_j)\) 是相对某参考模型的二维量。非共面目标、透视、遮挡和背景估计误差都影响它，不自动等于物理 object-only motion。

球随相机接近静止并不表示没有有用运动证据；背景的变化可能帮助形成参考。背景补偿也不是必选前处理：错误补偿会破坏本来能用的弱球证据。

第一版先把相机变化作为诊断维度。只有稳定失效与轻量参考确有增益时，才考虑增加估计；不由文献中出现 global/local 就引入重相机网络。

### 15.2 改变时间间隔不是只改变位移

固定目标帧、改变邻帧间隔，可以固定当前外观难度，但邻帧清晰度、可见性、碰撞阶段和背景仍同时变化。结果应叫“上下文间隔的联合影响”。

固定帧对和表示、只变搜索范围，才较直接针对搜索限制。两种实验互补；不能相互替代。

### 15.3 人工退化可以诊断，但不是新的真实球基准

全图已知平移用于等变性；控制压缩、噪声或模糊用于敏感性。它们不能自动独立改变真实球速度，也不能制造物理正确的曝光过程。

局部处理若没有球 mask，可能同时改了背景和边界；强模糊还可能改变端点标签的含义。因此，合成实验明确保存坐标有效条件，避开边缘评分，与自然视频结果分开。不能通过“合成可控”绕过真实目标定义。

## 16. 效率：分辨率不仅是空间网格大小

### 16.1 至少有四种不同的分辨率

输入 RGB 分辨率、特征网格分辨率、相关/状态网格分辨率、最终输出坐标分辨率不能混用。对粗网格作插值会改变读出位置集合，却不添加原始观测；提高输入或引入 RGB 细节会改变可用证据。

MEMFOF 提供一个有用的反例：它以较粗相关网格、更多通道和高分辨率训练获得有效权衡，说明“细相关网格一定是唯一正确路径”不成立。它也讨论滑窗特征与相关计算复用。其通用光流成绩仍不能证明 tiny-ball 成功。MEMFOF，ICCV 2025，§3–4[^s17]

### 16.2 控制总预算，而不是只控制匹配头

至少测完整编码、候选生成、关系计算、索引/gather、融合、读出和必要后处理。分别记录延迟、峰值显存、吞吐与训练资源；训练期 teacher 成本与部署期成本分开。

稀疏存储 \(NK\) 不等于构建 top-K 只需 \(NK\) 比较。全相关后 top-K、分块 exact top-K、近似搜索、结构化采样是不同成本。近似搜索还要评价检索损失。

### 16.3 流式缓存必须对主要对照公平

独立逐窗处理三帧会重复编码，连续 clip 中可能缓存共享帧；若只有新方法使用缓存，就会把实现差异误写成算法效率。所有可复用的主要基线应获得合理实现。

缓存以 clip 为界重置。离线三帧中心预测要把未来帧等待与纯计算时间分开；FPS 不能取代端到端延迟。训练时与测试时能否缓存是不同问题，不能无条件复用带随机增强的训练特征。

### 16.4 两张公平表足够，不做无法成立的“全相同”要求

第一张固定主骨干、输入与时间信息，帮助归因。第二张对齐完整资源预算，比较质量—成本。不同架构合理的学习率或通道配置可以不同，主要方法的调参机会应接近。

不要求同参数、同显存、同延迟、同 FLOPs、同输入和同表达能力同时成立；这是互相冲突的条件。记录差异比伪装成绝对公平更可信。

## 17. 统计结论：帧很多不等于独立证据很多

### 17.1 明确推断对象

固定测试视频上的帧级指标回答“在这些发布片段上表现如何”。跨比赛泛化还需要不同比赛来源的支持。若同一比赛的许多 rally 共享机位、场地和编码条件，它们不能无条件视为相互独立的域。

至少同时报告总体微平均与每个测试来源的结果。宏平均和微平均不是互相替代：前者防止长视频主导，后者反映帧总体表现。需要注明来源数、clip 数、有效目标帧数和可监督帧对数。

### 17.2 三个来源无法靠重采样变成很多来源

一个说明性例子：若只有三个独立测试来源，采用来源差值符号可交换假设下的双侧精确 sign-flip 检验，只有 \(2^3=8\) 种符号组合。以差值和的绝对值作统计量，即使三个来源都改善，最极端两种对称组合仍占 \(2/8=0.25\)。

这不是说任何统计方法都不可能显著，而是说明**该小样本设计本身限制证据分辨率**。把每一帧当作独立样本获得极小 p 值，并没有解决来源数量不足。

可以提供来源/clip 分层的重采样区间，但解释限于相应抽样假设。来源很少时，应更重视每来源效应、额外既有公开数据上的复核，以及诚实的不确定性描述，不把 bootstrap 次数当作证据量。

### 17.3 随机种子与视频来源是两种方差

重复训练种子帮助判断优化随机性；不同比赛帮助判断域变化。三次种子不等于三个新数据集，同一个模型跑很多随机增强也不能取代独立训练。

初筛可以少量运行，最终主方法与最强简单对照再做重复。若差异与训练波动相当，应收窄结论或继续检查，不设一个脱离任务容差和成本的通用“提升百分比门槛”。

### 17.4 防止把长期项目变成反复调测试集

数据协议、主要指标、主比较对象、有限调参范围和关键失败条件，在看最终测试结果前固定。探索性分桶可以做，但应明确是事后分析，并在其他既有来源或预留验证规则下复核。

不要尝试几十种模块只报告最好的单 seed。保留运行配置和失败实验，选定具体假设后再增加实验深度。本文列出的实验是按证据需求启动的队列，不是一次做完的笛卡尔积。

### 17.5 预训练数据重叠与下游泄漏分开

game/clip 划分防下游近邻泄漏，不能证明现代 web 预训练从未见过公开视频。DINOv3 的公开资料无法提供本项目可逐实例比对的完整预训练清单；因此记录权重来源、已知训练数据描述和可审计的近重复风险即可，不把无法获得的清单设为启动门槛。

黑盒 membership inference 的阴性结果也不能证明无污染。现有研究已指出这类评估会受基线和数据构造影响。本项目可以保留旧骨干/其他来源对照，但不声称由此排除一切重叠。Blind Baselines Beat Membership Inference Attacks for Foundation Models[^s18]

## 18. 最小可执行研究方案：先四份证据，再决定机制

### 18.1 第一份：协议与监督账本

先选一个明确的 TrackNet Tennis 来源级协议。记录原视频/clip、帧时间、位置约定、visibility、缺标规则和坐标变换。训练、验证、测试的窗口和状态不跨边界。

评价器应验证：GT 输入达到协议上限、已知像素偏移造成预期变化、missing 不计 negative、帧时间不重编号。这里尚不需要构建通用数据平台或下载所有候选数据。

**停止条件：**已选数据可产生可信的样本与指标，关键未知语义有明确处理；不能因另一个暂不使用的数据集标签不明，阻塞网球分支。

### 18.2 第二份：空间证据与读出表

首选 DINOv3 ConvNeXt-Tiny，ViT-S/16 作为另一种空间采样机制的对照。先比较少量层位、两个合理分辨率与一致容量的读出，避免同时搜索所有 Tiny/Small、adapter 和损失。

增加一个受控小平移诊断，确认位置/相位是否解释明显异常。若有细节分支，比较细节单独、骨干单独与组合，判断现代骨干的实际贡献。

**继续条件：**至少建立一个可信空间起点，或找到明确可修复的输入/读出问题。探针失败不是骨干永久出局；先排除读出容量、训练与尺度失配。

### 18.3 第三份：时间增量与错误互补表

保持主骨干、像素与合法窗口，先比较：

| 组 | 输入与能力 | 所回答的问题 |
|---|---|---|
| S | 当前帧定位 | 单帧能做多少 |
| S′ | 同类独立单帧运行，困难集开始参与决策时加入 | 多少“救回”只是错误互补 |
| T | 一个有竞争力的简单时序特征基线 | 廉价跨帧信息是否有净价值 |
| P | 同样单帧响应上的短窗路径/几何推理 | 高维描述子是否必要 |

若使用相同帧复制作为控制，只把它用来检查容量/训练变化，不把它当成真实运动反事实。重复帧模型和真实时序模型的训练分布不同。

**继续条件：**存在稳定的时序净收益或明确的可恢复失败。简单时序没提升，不足以逻辑上否定显式对应；但需要一个具体诊断理由，才能继续投入更贵路线。

### 18.4 第四份：覆盖—竞争—决策—成本表

以固定特征和分数，对局部搜索、粗全局细化、单侧稀疏和两端候选做受控诊断；实际只实现最能区分已观察瓶颈的两三个对照。若早候选化明显漏失，加入检测前累积的思想适配对照。

同时报告当前/历史/联合覆盖、标注中心 rank、最终位置/状态分解、困难集合及全集差值、完整资源成本。对于多峰，只在相同关系分数上先比较 top-1、有限 top-K 和平均压缩。

**继续条件：**出现一个具体且可重复的损失环节，现成简单替代尚未解决，并且修复确实改变最终决策。若只改 rank 不改定位，暂不把它作为定位论文主贡献。

### 18.5 然后才补完整归因与外部验证

主框架使用旧/新骨干 × 单帧/强简单时序/候选新机制的 2×3 归因；其中新骨干整套替换效应包含预训练、容量和优化因素，不能称为单纯架构因果效应。

先在网球选定机制，再用 BlurBall 检查模糊主张，用 Shuttlecock 验证另一球种。OpenTTGames 只在原时间和稀疏监督正确接入后使用。新发现的 TTHQ 可作为后续外部来源，不因此扩大第一阶段数据规模。

## 19. 三条候选假设及其否证方式

### H1：早期候选压缩造成了可避免的弱证据损失

**假设。**相同细粒度表征下，当前帧候选化过早丢掉一部分可由短时上下文提升的响应。适度延迟决策或保留更合适支持，可在预先声明的资源约束内，形成可重复的定位增益或更好的质量—成本权衡；同成本提高定位是强证据，但不是唯一有价值的结果。

**最强近邻。**NeuralTBD、Neural DP-TBD、SCV，以及各种检测前积累方法。

**最低差异证据。**共同观测和监督下，早/晚筛选的受控比较；误差互补控制；路径或候选的保留变化确实转化为定位净收益；错误路径没有吞掉收益。

**否证/转向。**只降低单帧阈值或简单路径打分已经达到同样效果；或者延迟筛选主要增加误检。此时不继续堆更多关系模块。

### H2：表示偏差与背景竞争的诊断族

**待选择的诊断因素。**在空间可读性足够的条件下，位置偏差、尺度失配、背景分数尾部都可能使真球关系被压低。它们是三个可独立成立的竞争解释，不能合成一个永远无法否证的“或者”假设。完成固定表示诊断后，只选择有明确证据的主导因素作为论文主假设，预先固定对应干预与失败条件，其余作为对照解释。

**最强近邻。**INSID3、Preserve Then Resolve、Needle-Match、ASpanFormer、LEAP-Track。

**最低差异证据。**同帧对、同候选预算的覆盖与 rank 分解；已有去偏/归一化/有限 top-K 基线；已知几何变化下的稳定性；完整位置收益。

**否证/转向。**已有无训练修正或简单归一化就解决问题；或者所谓改进只来自训练了更强球检测器。此时保留修正作为基础设置，重新寻找残余机制问题。

### H3：点中心描述子过于脆弱，关系支持应对应可见观测结构

**假设。**模糊时，单个标签中心的特征匹配弱于小邻域/线状观测支持；合适关系表达能帮助协议位置决策。

**最强近邻。**BlurBall、Needle-Match、MISA，以及区域和多尺度匹配工作。

**最低差异证据。**只在已有 blur 标签范围内，比较点、小邻域、简单方向支持，并加入等面积普通邻域对照。固定输入特征、时间帧、采样/计算预算与解码容量；不同支持本来就读取不同位置，不声称信息完全相同。发布的 blur 方向仅用于分桶、训练监督或明确标注的 oracle；正式 RGB 系统所用方向须由图像预测。明确无向轴与有向位移，区分中心约定偏移与真正定位改善。

**否证/转向。**换成协议中点目标或普通邻域平均即可解释全部收益；或只在有额外 blur 监督时有效，却被声称适用于所有球种。

### 不把 H1、H2、H3 一次性拼成网络

它们有交互，也可能共同成立，但第一篇应优先选择能形成最清晰证据链的一项。只有实际失败需要时才组合。每增加一项，应有独立的保留理由和相应反证对照。

新发现的 TTHQ 已有作者标注资源入口，但稀疏性、原视频取得和划分仍须使用前审计。1000 Rallies 与 TT4D 的已读资源声明不足以确认可直接下载使用的本任务数据；“将公开”不能写成“已可复现”。

## 22. 论文贡献与长期项目的收敛条件

### 22.1 一个有竞争力的贡献应由三件事共同组成

第一，发现一个稳定、非平凡、与任务条件相关的失效，而不是只展示球很小的截图。

第二，用一个可解释机制改变该失效；与最接近的已有方法比较，并排除更强空间检测、额外监督、阈值调整和实现缓存等主要替代解释。

第三，在完整定位和资源权衡上给出可重复收益，并在另一种有意义的观测条件或球种上复核。无需每张表都赢，也不因达到任意提升百分比就能保证论文等级。

### 22.2 不足以形成目标论文的结果

仅换 DINOv3 获益；仅提高输入分辨率获益；只在 GT query 上匹配更准；只减少已过滤样本的误差；只改善全图 flow；不同协议 F1 混排；或多模块组合有效却说不清来自哪一步。

这些结果可以作为研究素材或工程进展，但不足以支撑当前 motion representation 的核心叙事。

### 22.3 本阶段明确不做的扩展

不以新文献为理由加入视频 MLLM、巨型视频骨干、SLAM 或三维 reconstruction；不立刻新增球种；不创建通用训练平台；不把每个疑问都转化为一个 gate、loss 或 attention。

既有工具足以完成协议、空间、时序和支持诊断时，先用它们。若结果指向一个很小的修改，就研究这个修改，不用更多组件装饰论文。

### 22.4 何时停止继续写规划文档

当前已经有足够理由启动有界诊断。继续增加文献的价值应体现为改变最近邻、监督定义、实验对照或结论边界。若新搜索只增加外围题名，不改变任何决策，就停止本轮扩张。

下一个有价值的研究里程碑是四份真实证据：协议账本、空间读出表、时间净增量表、支持与成本表。**本文完成的是研究总纲与证据审查，不是这些实验的完成。**

## 23. 检索充分性、剩余风险与文档索引

### 23.1 实际覆盖方式

定向核对已知题名和 arXiv ID；以 `small/weak target + track-before-detect`、`sparse/global matching`、`DINOv3 correspondence/positional bias`、`ball tracking/blur/annotation`、`uncertainty/calibration` 等关键词族补检；沿关键论文引用追溯并核原始来源。

重点覆盖 2024–2026 的机制与近期预印本，同时保留 2016–2023 的直接先例。正式会议入口、arXiv 原稿、作者仓库和机构论文记录优先；二手摘要只用于发现，不作为关键技术结论依据。

未执行可复现的全库 arXiv API 枚举，没有逐篇全文审查所有相关领域，也没有复现各论文代码。部分 IEEE/出版社正文访问不足；摘要级条目不能用于排除未读的技术细节。故本报告不能声称系统综述式穷尽，更不能保证没有未索引或刚更新的新稿。

9 月 10 日定向补查再次核对了日期与任务边界。例如 CST-WM 的原始记录为 9 月 5 日提交，其任务是动作条件下的具身视觉跟踪与控制，因而仅作观测/动作混淆的外围参考，不加入固定体育视频定位基线。聚合站显示的更新日期不直接当成 arXiv 版本日期。[^s31]

### 23.2 尚未由文献解决的实证问题

| 未知 | 需要的最小后续证据 | 是否阻塞当前立项 |
|---|---|---|
| 现代骨干在真实球像素尺度上的表现 | 有效协议下的空间读出与轻量训练 | 不阻塞立项，阻塞“骨干更好”结论 |
| 球的高位移帧究竟在哪一环失败 | 固定表示和完整系统的分层诊断 | 阻塞具体创新锁定 |
| 双端候选是否漏掉关键帧 | 自动候选覆盖及困难集合组成 | 阻塞稀疏候选主张 |
| Blob/拖影中心关系是否帮助最终坐标 | 点/邻域关系与定位联合评价 | 阻塞强 blur-correspondence 结论 |
| 当前 Shuttlecock 坐标的拖影约定 | 实际发布包/标注说明 | 只阻塞依赖该约定的监督 |
| BlurBall 原始角度数值域与画线端点排序 | 发布 CSV/标注工具说明 | 不阻塞无向轴建模；公开代码已确认 orientation mod 180°，不能当有向速度 |
| OpenTTGames 各类标签的精确发布覆盖 | 原时间索引与 annotation manifest | 阻塞该数据接入，不阻塞 Tennis |
| 每帧图像球径与真实曝光参数 | 现有公开测量来源，若无则收窄主张 | 不新增人工标签来强行补齐 |
| web 预训练是否见过具体测试帧 | 可取得的来源记录与有限近重复审计 | 报告剩余风险，不设不可能门槛 |
| CCF B 或以上投稿是否有竞争力 | 机制、实验、写作与审稿时最新近邻 | 目前不能保证 |

## 24. 数学反例的复算说明

§8 的背景竞争表和 §17 的符号组合数只用于检验逻辑，不涉及实验数据。以下标准库代码可复算数字：

```python
from math import exp, log
from statistics import NormalDist

p = NormalDist().cdf(3.0)
values = [1 - exp(m * log(p)) for m in (1, 64, 1024, 36864)]
assert 0 < values[0] < values[1] < values[2] < values[3] <= 1
assert round(100 * values[1], 3) == 8.282
assert round(100 * values[2], 3) == 74.923
assert 2 / (2 ** 3) == 0.25
print(values)
```

该检查不能验证神经网络分数分布、真实标签误差、模型性能或论文创新。有关这些量的结论仍需真实实验。
