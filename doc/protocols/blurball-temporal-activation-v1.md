# BlurBall目标证据独立激活控制

版本：v1。日期：2026-09-14。状态：训练前锁定。

## 要回答的问题

[增强后残余](../experiments/2026-09-14-blurball-centered-hflip.md)有1876个第一候选位置错误，其中1228个在固定K16内没有4px候选。错误直接落在可区分的邻帧球位置附近只有9例，不能将时间位置错认作为主要动机。当前真正待检验的是：目标帧证据在第一次非线性之前与支持帧合并，是否限制其后形成准确的球响应。

源码中的第一投影把五帧各192通道合为32通道，然后GELU，再作1×1地址变换、3×3空间卷积、GELU及64通道读出。维度减少不是球信息消失的证据；本轮用一项保持参数量的控制直接测处理顺序。

## 唯一结构干预

设逐帧归一化特征为z_i，P_i是原960→32投影P中对应帧的列块，b是原偏置。基线第一激活为：

```text
h = GELU(sum_i P_i z_i + b)
```

新模型仅改成：

```text
a_target  = P_2 z_2 + b/5
a_support = sum_(i != 2) P_i z_i + 4b/5
h = GELU(a_target) + GELU(a_support)
```

后续address、spatial、第二个GELU、pixel shuffle、absence线性层完全沿用。P仍保存为原来的单个Conv2d参数，前向按列切分；不新增独立权重、辅助loss、门控、归一化、匹配范围或细节层。`interaction=target_activation`，目标槽明确为2。

去掉GELU时两路之和与原投影代数等价；加入GELU后函数类与激活统计改变，不能称为容量和优化完全相同。卷积乘加数不变，但增加一次32通道GELU、相加、特征/权重拼接和一次卷积调用；参数相同不保证实测耗时相同。支持四帧仍先合并，本轮也没有提前进行跨地址匹配。

独立审查建议用目标/支持两路，而非五帧分别激活：后者阳性不能定位到目标帧，且改变更多分支的激活统计。采纳两路，没有并行训练两种拆分，也不扫描偏置比例。

## 固定比较条件

参考为`outputs/blurball/centered_hflip/center5_seed0`的完整12轮结果，原运行不重训。新运行位于`outputs/blurball/temporal_activation/target_seed0`，从相同官方预训练与seed0随机初始化开始，不从参考best8接着训练。两臂模块构造与随机初始化顺序保持，参数均为1,279,169。

继承[同步翻转协议](blurball-centered-hflip-v1.md)：输入[t−2,t−1,t,t+1,t+2]，slot2；match00–17训练37590个共同目标，match18–21验证13912个，最终match22–25不使用。边界、原标签、512×288 RGB、batch4、FP32、seed0、同步水平翻转概率0.5、12轮、恒定AdamW与学习率均不变。

仍按原argmax本地F1@4选优，F1@8破平局，再取早轮次，含epoch0；固定best后计算radius7/T1局部重心及原q=0.5。新协议名称为`blurball-temporal-activation-v1`；除了interaction、protocol、输出目录、源码版本，不接受未声明的配置差异。

逐帧RGB mmap继续复用；训练时正常共同更新prefix，不缓存失效特征。验证复用批内相同帧编码。只导出一次固定K16坐标/分数/q，已有参考候选复用，后续分组只读数组。

## 验证和可推翻条件

先验证同seed全部初始参数逐值相同、线性极限下输出及梯度等价、目标槽切分与逐帧显式参考一致、V1/V0反向有效；真实B4确认全部时间槽的投影有有限非零梯度，并复现旧权重的小批量坐标/q。这些验证证明实现和对照语义，不证明性能。

主要机制证据为K16@4覆盖及K1固定局部PCK@4；同时报告@16、F1、q转换、救回/破坏、各match及位移/拖影条件。固定参考三类错误分区不能随新模型输出重定义，正确组也需保留以计入破坏。

本轮预设值得追加验证的开发信号为：K16@4净增加至少123个目标（约为原1228个漏候选的10%），且K1 PCK@4不退。原覆盖11461/12689，故需至少11584/12689；这是明确研究取舍的工程门槛，不是统计显著性界限。推荐替换开发基线还要求F1不退；如果只有候选覆盖增加而最终位置/输出退步，只保留机制观察，不替换。

若只有F1提高而K1/K16未提高，不支持目标位置证据改善解释；若位置和候选净增均不成立，停止该配方，不继续扫宽度、激活函数或偏置分配。单seed阳性需后续随机性验证，不能当成稳定贡献。若出现另一种位置收益，但没有达到候选门槛，也需按实际机制报告，不能事后修改门槛把它说成原假设成立。
