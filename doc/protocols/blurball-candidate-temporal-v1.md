# BlurBall有限候选的因果时序重排对照

日期：2026-09-13。状态：运行前固定，已完成；[结果与取舍](../experiments/2026-09-13-blurball-candidate-temporal.md)。

## 研究问题与边界

[候选覆盖](../experiments/2026-09-13-blurball-candidate-coverage.md)表明部分top1失败仍保留可定位次候选。本项检验一个明确竞争解释：既有检测输出的短程几何一致性，是否已能实现无GT的候选选择增量。它是简单后处理基线，不是新的motion representation贡献，也不复现KeepTrack；[候选关联先例](../literature/2026-09-12-distractor-association.md)中外观、身份初始化和持续记忆均不同。

只使用cross best3、既定16候选及固定局部重心；不改坐标、不改q、不更新backbone或原头。跨场景和跨seed结论不由本项单模型开发结果提供。验证使用全部match18–21的14,192个目标；train00–17的38,854个目标只用于选择本规则的一个强度参数。最终测试22–25不参与。

## 时间和输入

每个目标使用自身候选及前两个**真实相邻原帧**的候选。候选各来源于独立三帧定位窗口，因此合并视觉输入最多为`t−4:t`，无未来帧、无GT初始化。这与原三帧top1系统的时间范围不同；增量不能归因于同输入预算下的纯motion机制。两个时序规则使用相同五帧支撑。

原合法窗口先通过既定rally和内部边界处理。只有前两帧均存在合法目标预测，且它们原q都≥0.5时才启用重排；否则保持当前top1。未输出不等于物理无球，此处仅把原拒绝判断作为保守使用历史的规则。连续帧距离从原帧号判断，常速外推比例使用真实PTS时间差，不能把稀疏目标重新编号成连续帧。边界后的前两个合法目标因历史不足保持原预测；所有目标仍进入评价。

不递归使用前一步重排结果：每个输出只读取保存的原候选，所以没有跨窗口长期轨迹/身份反馈或错误自我强化的状态。历史候选坐标只是先验，不能称为当前帧视觉对应。

历史链接需同时满足相同game/clip、原帧号逐帧连续、两段PTS差均为正；不满足就回退top1。报告时区分结构缺历史、历史存在但被原q拒绝、历史规则实际可用，不能混称“无历史”。

## 两个固定规则

对每帧候选的peak logit减去该帧top1 logit，得到相对分数`s≤0`；减去常数不改变当前排序，也不把这些分数解释成校准概率。令当前位置为`x_i`，前一帧为`y_j`，前两帧为`z_k`，候选均K=16。

当前候选评分：

几何评分与最终输出均使用已保存的`local_xy`；`peak_logits`只作为单帧候选分数，不混用格中心坐标。

`S_i = s_current[i] + max_(j,k)(s_near[j] + s_far[k] − λ E_ijk)`。

两个规则只改变几何惩罚：

- stationary：`E=(||x−y||²+||x−z||²)/(2×4²)`，表示位置持续的零阶先验；不是相机运动补偿。
- velocity：`E=||x−y−r(y−z)||²/4²`，其中`r=(time_t−time_(t−1))/(time_(t−1)−time_(t−2))`，表示局部常速先验。

4px仅用作已定细定位单位，实际强度由λ决定，不声称是测得的运动噪声。无位移硬截断、无GT搜索范围、无重新插值、无隐式未来；最多枚举16³条短路径。独立窗口处理后，选择最高`S_i`，并列优先原候选次序。λ=0时精确退化为top1，而非另一条隐式历史聚合。

每个规则分别只在训练侧从`[0,1/16,1/4,1,4]`选择λ：先最大化原q下严格4px的TP，再最大化全部V1的4px正确数，再取较小λ。因为q固定，主要准则与训练侧本地F1@4一致。候选与GT仅在选参/评价阶段相遇，推理函数不接收GT或visibility。

训练候选来自该模型训练过的图像，较高拟合度可能使选参偏保守；这项限制明确保留，不把训练集选择叫作独立校准。如果选到0，报告该规则没有被训练侧证据选中，不事后看验证挑一个非零λ。常速在击球、反弹、遮挡、相机变化时可能不合适；零阶先验可能偏好稳定背景。正反结果都只约束这两个具体规则。

## 执行、评价与判断

先导出训练候选一次，复用现有逐帧RGB及候选提取实现；验证候选直接读取上轮NPZ，零次验证forward。执行顺序为：训练候选与原训练argmax/q复现 → CPU训练侧选参并保存选择 → 验证两条选定规则 → 完整分组及正反配对。不会减少batch或只挑失败子集。

报告全部目标的PCK@4/8/16、本地F1与V1/V0状态；同时报告四比赛、位移/拖影、历史可用/不可用以及固定202/74群体。配对方向固定为top1→重排，区分救回、破坏与q拒绝。所有V0的原q保持，误出数量应不变；这不保证误出位置相同。候选覆盖上限不重新forward、不重新挑K。

另外用GT仅作评价分组：当前候选4/16px覆盖、三个时刻都覆盖，以及三帧均V1下的图像平面常速外推残差`<4/4–16/≥16px`。该残差是非匀速代理，不能自动标为碰撞或球的物理加速度。分开报告候选遗漏与几何规则失败。三时刻覆盖不是本规则成功的必要条件，错误历史也可能偶然外推到正确位置，因此不能称它为严格上限。velocity相对top1提高仍不足以说明速度关系有效，还要比较同时间范围的stationary；若两者相当，只保留一般时间稳定性解释。

只有实际自动定位在总体PCK@4与本地F1@4均提高、PCK@16不降、各验证比赛PCK@4不降时，才保留为候选后处理基线。否则停止这套配方，不加大λ扫描、不加更多训练。即使通过，也须与同时间范围的后续模型比较，不能把它直接称为新motion贡献。

实现位于`probe_blurball_candidates.py`的共享提取、`export_blurball_candidates.py`的训练导出及`rerank_blurball_candidates.py`的CPU时序选择。输出在`outputs/blurball/spatial_interaction/candidate_temporal/`，保留训练紧凑候选、选择参数、验证预测和完整结果。无用的大型临时张量不落盘。

定向测试验证原帧缺口/片段边界回退、时间差比例、常速与静止可区分、λ=0保持、未来候选变化不影响过去输出及原q拒绝门控。复用候选提取和原读出测试；不触发重训或最终测试读取。
