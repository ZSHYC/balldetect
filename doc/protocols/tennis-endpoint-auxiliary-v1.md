# Tennis可见中心端点的训练期辅助监督

状态：已锁定；版本：v1；锁定日期：2026-09-11。

继承[全量因果定位协议](tennis-full-causal-v1.md)与[完整时序控制](tennis-full-temporal-control-v1.md)。依据是[真实历史的已完成增量](../experiments/2026-09-11-full-temporal-control.md)及[跨格分组](../experiments/2026-09-11-search-support.md)，不是已证明的内部对应失败。

## 有限假设与对照

检验：在同一可训练DINO前缀与三帧自动定位头下，训练期用当前实例描述子给历史端点候选排序，是否比仅用共享球外观给同一批候选排序，更有利于局部端点区分和自动定位。

三组为已完成的无辅助full-history、重新初始化训练的relation辅助、重新初始化训练的appearance辅助。后两组共用当前GT位置定义的ROI、历史候选、有效pair、目标类别、温度与主定位任务。appearance组以一个全局可训练192维向量w替代当前实例query；它不比较两帧描述子，但训练ROI仍来自当前标签，因此不能称无时序标签控制。

不采用全图空间辅助头：将25/81类换成2,304类会额外改变候选空间和归一化。也不重启远时刻错配历史、cost通道拼接或半径扫描。

## 数据、几何与合法监督

保持games1–6训练、game7验证；同一14,160帧RGB缓存、12,167/1,863个合法末帧目标、真实[t−2,t−1,t]。最终games8–10不进入本轮。原始标注与时间索引不变，不重新解码。

辅助native grid为36×64，坐标仍按像素中心映射：`gx=floor((x+.5)*64/1280)`，`gy=floor((y+.5)*36/720)`。只有当前与相应历史帧均为原始VC1、位于同一合法窗口，且历史GT格位于固定候选范围内，才计算该pair的辅助损失。VC0/2/3和范围外pair保留主任务监督，但不伪造正匹配或no-match类别。

Δ1使用t−1、半径2、25个offset；Δ2使用t−2、半径4、81个offset。offset按dy后dx的row-major顺序排列，目标为历史格减当前格。候选中的图像越界格在softmax前置为负无穷；不得用零特征或−2有限分数冒充有效候选。不存在的类别也不参与归一化。

原始VC1表示源标注的可见状态，不保证两个native格包含同一物理球表面。标签只规定“历史标注中心类别”；其它格不是已标注的物理背景。模糊、格点相位和重叠感受野会给硬中心监督带来噪声，本轮不据验证结果改成软标签。

## 计算与损失

共享前缀输出每帧192×36×64特征。复用本次forward，逐帧减去空间均值，再对被读取的query/key作通道L2归一化；不生成全图dense cost或新特征缓存。

relation的query为当前GT格的归一化特征，appearance的query为归一化w。两者均与历史候选key点积，再除以固定温度τ=0.1。对正确offset做交叉熵。每个Δ先对本batch有效pair求均值，再对非空Δ等权平均；只有一个非空Δ时使用它，无有效pair时辅助损失为0。主CE仍对全部目标求均值。

relation的系数固定λ=0.1。为限制两臂起始辅助强度的差异，仅在共同初始化、固定训练batch上做一次校准：按缓存训练顺序，从头取第一个同时包含两种Δ有效pair的batch8，计算两种未加权辅助损失对全部共享prefix参数的梯度L2范数，设`λ_appearance = 0.1 * norm(g_relation) / norm(g_appearance)`。保存batch身份、有效数量、两范数、λ以及relation加权辅助/main梯度范数比；不使用验证标签、不扫描或再调系数。若范数为0或非有限，修复实现后再训练。

这只匹配初始batch的梯度尺度，不能保证训练全程强度、梯度方向或任务难度一致。relation还多了当前query输入及其梯度；阳性结果不能进一步拆成“描述子比较本身”的单独作用。

## 初始化、训练与选优

三组共享官方ConvNeXt-Tiny前两stage及随机SpatialProbe的既有初始化顺序。新辅助对象在共同模型之后创建；w用独立CPU生成器seed0采样标准正态并初始归一化，不能改变主头初始化或训练样本顺序。relation不增加参数；appearance的192个参数仅训练时使用，学习率3e−4、AdamW weight decay0.01，另外记录训练参数数目。

保持seed0、batch8、float32、无AMP、无增强、30epoch；prefix/head学习率1e−5/3e−4、AdamW weight decay0.01。前缀保持eval模式且允许梯度；主位置/absence CE、576通道、hidden32、72×128输出和presence阈值不变。仍只按验证detection F1@16、其次F1@8、同分先出现的epoch选优，含epoch0；不按辅助排名选checkpoint。

推理只保留原prefix和SpatialProbe，不读取GT、w或辅助候选。正式训练保存辅助系数、主/辅助损失、w状态（仅appearance）、源版本和命令，主模型checkpoint格式继续可被既有评价使用。两臂串行使用GPU。统计实际总时长和峰值显存；离线校准单列成本，不称训练免费。

## 直接机制读数与判定

在各自按主任务选出的checkpoint上，用同一game7双端VC1、in-range pair集合测量**relation query**的局部exact R@1及target NLL，保持同一τ、候选与mask；appearance模型也用其当前实例特征测量，不能拿w的排序冒充对应排序。按Δ1/Δ2分别报告all、same-cell、moved及clip，不把两个Δ当独立样本。w本身的辅助读数可补充，但不替代共同relation测量。

预定方向门控：relation相对无辅助与appearance均提高自动PCK@8和F1@16，同时两Δ等权宏平均的local exact R@1提高、NLL降低；跨格子集也须具有同方向的宏平均变化。逐Δ和逐clip的反向结果必须报告；单seed、单game不用于显著性或普适性声明。

- 排序改善、自动指标不改善：当前辅助没有转化为自动定位收益，不能据此称motion模块有效。
- 自动指标改善、预定排序不改善：不能归因于这里预设的端点关系机制。
- appearance与relation相近：额外端点/外观监督仍足以解释收益。
- relation同时通过上述方向：只支持继续检验这种实例条件辅助与结构化融合；不证明已获得物理位移、自动对应发现或方法新颖性。

单个阴性配置只否定这组温度、权重和表示/监督配方，不证明所有correspondence学习无效；本轮不以扫描更多超参挽救假设。

## 实施验证范围

新增稀疏候选与损失的一个合成检查，覆盖端点方向、VC排除、越界归一化、空pair和两臂梯度去向。一次真实训练batch同时验证主forward等价、共同初始化未变、有限主/辅助梯度及初始尺度；失败就修正对应实现，不启动正式训练。复用既有窗口与预测测试，不为纯文档重跑数据审查。

文献近邻核对与实际命令、数值、运行状态写入相应实验记录；实现前已获得DINO-Tracker、LoFTR与点跟踪路线的直接先例结论。该训练辅助是机制诊断，不作为新算法贡献申报。
